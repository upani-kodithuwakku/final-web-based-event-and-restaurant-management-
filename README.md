# Restaurant and Event Management — Team Starter

This is a folder-only starter based on the existing project. It contains no implementation, dependency manifests, database scripts, credentials, or previous Git history. It is not runnable yet.

## Structure

- `restaurant-event-backend/src/main/java/com/group06/restaurantevent/`: Java backend feature packages and shared infrastructure.
- `restaurant-event-backend/src/main/resources/db/migration/`: database migrations.
- `restaurant-event-backend/src/test/java/`: backend tests.
- `restaurant-event-frontend/src/`: React components, context, pages, and services.
- `restaurant-event-frontend/public/`: static assets.
- `database/`: database setup scripts.

See FOLDER_STRUCTURE.md for every directory. Empty leaf directories contain `.gitkeep` because Git tracks files, not empty directories. Remove a placeholder when adding real files to its directory.

## Start coding

The reference project uses Java 21, Spring Boot, Maven, MySQL, React, TypeScript, and Vite. Agree on dependency versions as a team and add the backend and frontend build configuration, entry points, and environment examples before trying to run the app.

Assign feature ownership before development. Keep shared configuration and API contracts coordinated. Each member should create a feature branch, push their work, and open a pull request into main for review.

Reference project: https://github.com/upani-kodithuwakku/web-based-event-and-restaurant-management-

The starter preserves the main application folders. Generated build folders, installed dependencies, previous member-package copies, and existing documentation are omitted.
